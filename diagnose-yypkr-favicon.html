ℹ️ 技术说明

什么是 CDN？

CDN（内容分发网络）是 GitHub Pages 用来加速网站访问的全球服务器网络。当您更新网站后，CDN 需要在所有服务器上同步新内容，这需要一定时间。

为什么其他成员有图标？

Chen Kangwen 和 Chen Yuzhe 的个人页面也是同样的情况，他们的图标可能在您之前就已经同步完成了。

如何确认配置正确？

您可以通过以下方式验证：

  1. 查看网页源代码，确认有 <link rel="icon" href="favicon.svg?v=1">
  2. 检查 GitHub 仓库中是否有 favicon.svg 文件
  3. 使用浏览器开发者工具（F12）查看 Network 标签，确认 favicon.svg 被加载
