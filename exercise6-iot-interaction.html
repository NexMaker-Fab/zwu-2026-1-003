Daily Life IoT Case: Smart Robot Vacuum Cleaner (Cloud-Edge-End Architecture)

I. Definition of Each Layer

  • End (Terminal Device): Robot vacuum cleaner body (LiDAR, dust sensor, motor, WiFi module, collision sensor)
  • Edge (Edge Node): Home WiFi router (local edge gateway, processes data nearby, reduces cloud latency)
  • Cloud (Cloud Platform): Brand IoT cloud server (data storage, AI path planning, remote command dispatch, device management)

II. Complete Operation Process (Remote Start Cleaning via Mobile)

  1. User opens Mi Home / ECOVACS APP and issues a "Full House Cleaning" command
  2. The command is uploaded to the cloud via mobile data / WiFi
  3. The cloud verifies device binding permissions and forwards the control signal to the home edge gateway (router)
  4. The edge gateway locally forwards the signal to the robot vacuum terminal device
  5. Terminal startup: LiDAR scans the room, dust sensor detects dirty areas, drive motor starts cleaning
  6. Robot collects in real-time: position, dust level, battery, fault status, and sends data to the edge gateway first
  7. Edge layer local pre-processing: filters redundant useless data, only uploads key information to the cloud, reducing traffic
  8. Cloud stores cleaning records, AI optimizes cleaning routes, syncs real-time status back to mobile APP
  9. After cleaning is complete, terminal auto-returns to charging dock, status is synced through edge and cloud to mobile, pushing a cleaning completion notification
