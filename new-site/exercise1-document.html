Website Development Guide

Prepare tools for website:
  • Github: Our website will be placed here.
  • GitHub Desktop: Used for cloning libraries and uploading local files.
  • AI agent (TONGYI Lingma): Used to write website code.

1Step one: Create a new repository on GitHub to host your website

Create a public repository where you can collaborate with your team to create web content.

Name your repository, choose whether it's public or private. Add a README file to share your information, then click the "create repository" button.

2Set the page to be empty

Click on the settings of the repository and select "Pages" on the left.

Choose "main" and "/root" and save.

The link above allows you to view the page.

3Wait for Github to search and create pages

Once all projects are completed, the website will be initially established.

4Step two: Clone the repository to GitHub

Click on "Add", "Clone a resource", find the repository you want to clone.

Finally, click "Clone".

5Step three: Design website with your team in AI agent

Use AI agents to design the functions and layout of web pages.

(Only one picture is provided for reference.)

6Step four: Upload them to Github

Upload directly to the corresponding GitHub account via Lingma.
